# 株式会社白石 資料請求用営業資料

株式会社白石のDXサービス（DXコンサル／Lark構築／アプリ開発）に関する資料請求用の営業資料です。
株式会社YUXYの提案テンプレート（A4横・6ページ、白×紺×金の配色）をベースに作成しています。

## ファイル構成

| ファイル | 用途 |
|---|---|
| `_shiraishi_document_request_inner.source.html` | 作業マスター（`<style>`+本体+`<script>`）。Artifact公開等はこれをそのまま貼る |
| `shiraishi_document_request.html` | 標準版（`<!doctype>`付き）。ブラウザで開いて印刷=PDF化する用 |
| `shiraishi_document_request.pdf` | 出力サンプル（A4横 841.92×595.92pt・6ページ） |
| `print.js` | Playwright(Chromium)でA4横PDFを生成するスクリプト |

## フォントについて

生成環境にYu Mincho/Hiragino等の日本語フォントが無いと、見出し内の欧文（AI・DX等）だけ
別書体にフォールバックし「フォントがぐちゃぐちゃ」に見えます。`fonts-noto-cjk`
（Noto Sans/Serif CJK JP）をフォールバックに追加して解消済みです。実際にWindows/Macで
開く場合はYu Mincho・Hiragino系が優先されるため表示は変わりません。

## ★要確認：P1/P6とP2の会社主体の不一致

P1・P6はYUXY提案テンプレートをそのまま使用したため、**株式会社YUXYが送り主、株式会社白石が宛先**という構成になっています。
一方P2は「株式会社白石」自身の事業紹介・代表挨拶のままです。どちらが正しい送付形態か（YUXYが白石に提案する資料 or 白石が自社の見込み客に送る資料）に応じて、P2の書き手を統一する必要があります。次回の指示をお待ちします。
