# 株式会社白石 資料請求用営業資料

株式会社白石のDXサービス（DXコンサル／Lark構築／アプリ開発）に関する資料請求用の営業資料です。
株式会社YUXYの提案テンプレート（A4横・6ページ、白×紺×金の配色）をベースに作成しています。

## ファイル構成

| ファイル | 用途 |
|---|---|
| `_shiraishi_document_request_inner.source.html` | 作業マスター（`<style>`+本体+`<script>`）。Artifact公開等はこれをそのまま貼る |
| `shiraishi_document_request.html` | 標準版（`<!doctype>`付き）。ブラウザで開いて印刷=PDF化する用 |
| `shiraishi_document_request.pdf` | 出力サンプル（A4横 841.92×595.92pt・6ページ） |

## ページ構成

| P | 内容 |
|---|---|
| 1 | 表紙 ―「AI社員を雇って、DXしませんか。」 |
| 2 | 事業紹介・代表挨拶（統合）― 事業3本柱（DXコンサル／Lark構築／アプリ開発）、特徴3点（現場に強い／経営に強い／充実した開発基盤）、代表挨拶＋写真枠 |
| 3 | 実績紹介 ― 警備会社の月次シフト管理を5分で完成させた事例 |
| 4 | Lark導入効果シミュレーション ― 営業人員×業種別の改善額イメージ（試算例） |
| 5 | DXOne紹介（価格表示なし）― 中小企業DX One（提供：株式会社ユニクス）の特徴 |
| 6 | クロージング ― 会社情報、打ち合わせ予約リンク・QR |

## 送付前に必ず埋めること（`［ ］`で全文検索）

実在の企業に送付する資料のため、以下は空欄・仮テキストのままです。差し替えてから送付してください。

- [ ] P1：宛先企業名・部署名・提案年月・正式ロゴ
- [ ] P2：代表者写真・代表者氏名・代表挨拶文
- [ ] P3：シフト作成の「従来の所要時間」（Before値）
- [ ] P4：Lark導入シミュレーションの業種別サンプル数値（イメージ例として算出のうえ記入、または個別算出に置き換え）
- [ ] P6：代表者氏名・TEL・Email・所在地・受付時間・設立年月・打ち合わせ予約URL・QRコード

## QA チェックリスト

- [ ] `［` で全文検索 → 差し替え漏れがないか確認
- [ ] PDFが **6ページ・841.92×595.92pt（A4横）**
- [ ] P6のCTAボタン・QRが実際の打ち合わせ予約URLに向いている
- [ ] P4の改善額は「試算例」であることが明記されている（断定表現になっていない）
- [ ] 「中小企業DX One」の提供元（株式会社ユニクス）表記が残っている

## 生成コマンド（参考）

```bash
node print.js shiraishi_document_request.html shiraishi_document_request.pdf   # Playwright(Chromium)でA4横PDF化
pdftoppm -png -r 150 shiraishi_document_request.pdf page                       # 目視QA用に画像化
```
