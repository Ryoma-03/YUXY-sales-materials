# 株式会社白石 資料請求用営業資料

株式会社白石のDXサービス（DXコンサル／Lark構築／アプリ開発）に関する資料請求用の営業資料です。
株式会社YUXYの提案テンプレート（A4横・6ページ、白×紺×金の配色）をベースに作成しています。

## ファイル構成

| ファイル | 用途 |
|---|---|
| `_shiraishi_document_request_inner.source.html` | 作業マスター（`<style>`+本体+`<script>`）。Artifact公開等はこれをそのまま貼る |
| `shiraishi_document_request.html` | 標準版（`<!doctype>`付き）。ブラウザで開いて印刷=PDF化する用 |
| `shiraishi_document_request.pdf` | 出力サンプル（A4横 841.92×595.92pt・6ページ） |
| `print.js` | Playwright(Chromium)でA4横PDFを生成するスクリプト |

## フォントについて（2回目の修正で全面変更）

1回目は不足していたNoto CJKフォントを追加するだけでしたが、それでも「見出し=明朝／本文
=ゴシック」の2書体混在が気になるとのご指摘を受け、**見出しも含めて全ページゴシック体に
統一**しました（`--f-mincho`トークンを`--f-gothic`と同一の値に変更）。参考PDF
（YUXY×ジーエフホールディングス様提案資料）と同じ、ゴシック単一書体の構成です。

## P2「Why 白石」カードについて

参考PDF3ページ目の構成にならい、「現場に強い／経営に強い／充実した開発基盤」を
大きな採番＋タイトル＋英字キャプション＋本文＋結びの納得構文（∴ だから…）という
構成に刷新。事業紹介（DXコンサル/Lark構築/アプリ開発）はアイコン付きの帯に圧縮し、
1ページに収まるようレイアウトを整理しました。

## P3実績紹介について

実在のシフト管理システムを参考に、URLの記載は削除。代わりに実際の入力パラメータ
（社内資格＝スキルマップ／希望休シフト／セクションローテーション：1〜2時間ごとに
バックオフィス→窓口対応→巡回警備を交代）をもとにした「3条件で自動振り分け」を
明記しました。業種が特定されないよう「施設警備会社」という表現に留めています。

## P4 Lark導入について

P3で判明した実際の入力パラメータ（資格・希望休・ローテーション）を踏まえ、
「複雑な条件をLarkで仕組み化する」という切り口に全面刷新。人員配置の最適化・承認
ルーティング・発注条件の自動判定など、同じ考え方が活きる業務例を提示しています。

## P5 DXOne紹介について

`https://www.uniq-s.co.jp/dxone/` と PR TIMES記事のURLはネットワーク制限により
本環境から取得できなかったため、既存のDXOne製品資料（PDF）の内容をもとにレイアウトを
刷新しました。「DX Oneの“AI社員”」と「よくあるAIアシスタント」の比較を主役に配置し、
デジタル化・AI導入補助金2026の対象ツールである旨をバッジで明記（金額は非表示のまま）。
対応業務（営業・総務・業務横断）の範囲も追加し、説得力を強化しています。

## ★要確認：P1/P6とP2の会社主体の不一致

P1・P6はYUXY提案テンプレートをそのまま使用したため、**株式会社YUXYが送り主、株式会社白石が宛先**という構成になっています。
一方P2は「株式会社白石」自身の事業紹介・代表挨拶のままです。どちらが正しい送付形態か（YUXYが白石に提案する資料 or 白石が自社の見込み客に送る資料）に応じて、P2の書き手を統一する必要があります。次回の指示をお待ちします。
